# Runtime patch review: rust-v0.155.0-alpha.9.2

The `rust-v0.155.0-alpha.2.6` Boss patch no longer applies mechanically to
`rust-v0.155.0-alpha.9.2` because upstream moved two ownership seams:

- child spawn and resume configuration moved from
  `tools/handlers/multi_agents_common.rs` to `agent/child_config.rs`;
- v2 message delivery and wake behavior moved from the tool handlers to
  `agent/control/delivery.rs`.

The adapted patch keeps the existing Boss semantics at those new ownership
points: workers recover the root's original permission profile and hybrid base,
and `send_message` wakes an idle worker without turning the message into a new
task. Upstream Guardian filtering, allowed-tool filtering, instruction reload,
and personality behavior remain intact.

Validation gate: targeted Boss tests, `scripts/test.sh --cargo`, a release
build, and a fresh local state check.
